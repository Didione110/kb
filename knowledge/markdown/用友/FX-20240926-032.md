## 问题现象

2022年年末试算平衡，2023年期初结转过来不平

## 问题原因

底层科目档案末级标识有误

## 解决方案

是222101科目与下级一起参与了多次汇总到一级导致，数据库检查科目档案
select * from code where ccode='222101' and iyear='2023'
发现222101作为下面还有下级的科目打上了末级标识（bend='1'），执行语句修改
update code set bend='0' where ccode='222101' and iyear='2023'
执行成功后重新结转，解决
