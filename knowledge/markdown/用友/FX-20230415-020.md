## 问题现象

生单时保存报：无法解决 equal to 运算中 "SQL_Latin1_General_CP1_CI_AS" 和 "Chinese_PRC_CI_AS" 之间的排序规则冲突 错误

## 问题原因

系统数据库引擎排序规则有问题

## 解决方案

查看数据库的系统数据库属性，排序规则是SQL_Latin1_General_CP1_CI_AS，而建的企业库排序规则是Chinese_PRC_CI_AS，这里就会产生冲突，导致单据保存不了，由于是系统库，用语句是修改不了的，解决方法二选一，一是新增一个实例；二是彻底重装数据库，到【自定义 SQL Server 2019 数据库引警排序规则】时，手动更改为Chinese_PRC（一般是默认的），即可。
