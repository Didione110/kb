## 问题现象

银行日记账修改提示：记录号为:SC_BOOK0000425752的记录已经被用户加锁,不能对其进行[MD:修改]操作

## 问题原因

单据被加锁，不能修改

## 解决方案

1、在日记账界面多按几次ctrl+Q，没有生效，还是报错
2、执行语句：查询出纳锁定表的报错的单号--select * from CN_LockAcctBook where id ='SC_BOOK0000425752'
修改报错单号--update CN_LockAcctBook set id ='SC_BOOK0000425752_bak' where autoid =190378
