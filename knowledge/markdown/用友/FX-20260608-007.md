## 问题现象

报表数据查询

## 问题原因

三大报表低版本无API ，只能从系统直接取数

## 解决方案

--首先根据iufo_keyword 查询对应关键字主键是什么 对应的是PK_KEYWORD
select * from iufo_keyword
--根据自己报表定义的关键字组合。从iufo_key_comb找到对应的关键字组合主键
PK_KEY_COMB
select * from iufo_key_comb
--根据上面脚本的关键字组合主键在iufo_measure_pubdata(指标数据主表)中对应字段
ktype 过滤出想要查询的数据
select * from iufo_measure_pubdata where ktype = '上面查询出的关键字组合主键'
--然后根据iufo_measure_pubdata(指标数据主表)中的 keyword1-keyword110对应的具
体的值，比如 1000公司的 2019-10的cny的表，找到对应的alone_id，ver是版本号，要查
企业报表的话版本为0，合并报表是510
select alone_id from iufo_measure_pubdata where ktype = '上面查询出的关键字组合
主键' and KEYWORD1 ='对应公司的主键在iufo_unit_info表中查' and KEYWORD2 = '对
应的日期'and KEYWORD3 ='对应的币种' and ver = 0 等等;
--然后根据alone_id和打开报表表样找到指标管理里看见的对应的指标所在的表查询数据即
可（存在iufo_measure表中的MEASURES blob二进制字段中）
