## 问题原因

NCC 2005 因为在【单据类型管理】节点找到对应的交易类型设置中，前台去掉了【是否轻量化单据】
这个选项，需要修改后台数据实现

## 解决方案

1.执行如下脚本
--备份表
create table bd_billtype_copy as select * from bd_billtype
--更改 islight 为 N，表示只在重量端接收消息
update bd_billtype set islightbill = 'N' where pk_billtypecode='单据类型编码'
--更改 islight 为 Y，表示只在轻量端端接收消息
update bd_billtype set islightbill = 'Y' where pk_billtypecode='单据类型编码'
2.重启中间件
