## 问题现象

在使用u8c的api进行对接时，摘要字段分为2部分，即在发送报文时explanation字段在detail和voucher2个子集均存在
{
 "voucher" : [{
 "details" : [{
 "explanation" : "测试0902熊啸会计", 
 "pk_accsubj" : "100202", 
 "pk_currtype" : "CNY", 
 "creditamount" : 10, 
 
 }, {
 "explanation" : "测试熊啸会计的供应商",
 "pk_accsubj" : "220201",
 "pk_currtype" : "CNY",
 "debitamount" : 10, 
 "ass" : [{
 "checktypecode" : "73",
 
 "checkvaluecode" : "001069" 
 
 } 
 ]
 }
 ],
 "pk_corp" : "0301", 
 "pk_glorgbook" : "0301-TJ01", 
 "pk_prepared" : "13297000330", 
 "pk_vouchertype" : "记账" 
 "explanation" : "测试0902熊啸会计", 
 }
 ]
}

## 问题原因

在编制接口程序组织报文时，explanation根据经验会区分汇总和明细，但是U8c的前端页面，汇总摘要的显示方式并不是取的字段，而是取的凭证明细分录的第一行的摘要，容易给实施造成误解

## 解决方案

组织json部分的 "explanation"字段时，保持内容与details明细条目的第一条的 "explanation"对应一致即可
