## 问题现象

现金管理单据摘要太长了导致生成凭证报错

## 问题原因

后台字段太短了需要加长

## 解决方案

执行下列语句修改后台最大字段
区分数据库
oracle数据库执行：
alter table dap_rtvouch modify assino varchar2(255); 
alter table dap_rtvouch_b modify assino varchar2(255); 
sqlserver数据库执行：
ALTER TABLE dap_rtvouch ALTER COLUMN assino VARCHAR(255); 
ALTER TABLE dap_rtvouch_b ALTER COLUMN assino VARCHAR(255);
