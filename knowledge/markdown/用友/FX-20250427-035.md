## 问题现象

出纳模块结账始终提示未全部过账；实际反复检查确认全月已完成全部过账，查询期间只选择了月，出来的全部数据都是灰色，结账就是提示此账户有未全部过账的数据；

## 问题原因

后台异常

## 解决方案

select * from CN_AcctInfo where lyear='2021'
先用账户表查出账户ID
再过滤出21年11月，36账户的所有流水记录 并且找到IsAudited是否过账标识为0的，是147号凭证相关的9条记录，尝试重新手工一条一条过账，仍不行，最后决定修改数据库；
select IsAudited,* from CN_AcctBook where lyear='2021' 
and acctid='36' and period='11' and IsAudited<>'1' order by voucherstr
select IsAudited,* from CN_AcctBook where id='33991'
update CN_AcctBook set IsAudited='1' where id='33991'
处理后正常结账
