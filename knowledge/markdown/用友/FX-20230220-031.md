## 问题现象

固定资产增加提示“Invalid cell reference.Wrong in SetF1Book ofclsCards”

## 问题原因

数据库后台固定资产卡片项目样式设置表中年度是2022（不是现在年度）

## 解决方案

备份，数据库后台处理
select * from fa_ItemsOfModel（查出后台固定资产卡片项目样式设置表中年度是2022）
update fa_ItemsOfModel set iyear=2023 where iyear=2022（将2022修改为正确的2023），解决
