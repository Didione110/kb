## 问题现象

应付单导入时，导入模板中部门填写的名称过长，报错显示部门长度超过字符20；

## 问题原因

单据导入部门长度已经代码控制

## 解决方案

1、在首页录日志spr--打开相应节点--关闭spr--查找spr中的第一个语句中pk_page_templet的主键，根据语句执行第二个第三个语句
select pub_page_templet.ts from pub_page_templet where pub_page_templet.dr = 0 and pk_page_templet = '1001A9100000000E98AZ' 

SELECT * FROM pub_form_property WHERE areaid IN (SELECT pk_area FROM pub_area WHERE templetid = '1001A9100000000E9NP3' ) AND REFNAME like '%部门%'

update pub_form_property set maxlength =1000 WHERE areaid IN (SELECT pk_area FROM pub_area WHERE templetid = '1001A9100000000E9NP3' ) AND REFNAME like '%部门%'

2、到home中这个文件resources\excel\billdefine\arap\F1.xml修改部门的maxlength；部门和部门版本都要改，每个文件中表头表体共四处
