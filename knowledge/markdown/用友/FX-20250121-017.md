## 问题现象

批量将A业务单元的客商分配给B业务单元

## 问题原因

子公司架构变动及其他原因，更换账套，需要批量复制档案

## 解决方案

选择一个不用的自定义项，例如30
将原A业务单元的客户都打上标，如2030，
update bd_customer set def30 = '2030' where pk_customer in (select pk_customer from bd_custorg where pk_org in (select pk_org from org_orgs where code = '1008'));
commit;
查询确认成功后，再到客户-集团的分配向导里过滤自定义30等于2030的档案，统一分配给新业务单元即可
