## 问题现象

销售发货单，调拨单启用word打印模板

## 问题原因

标准功能里U8的销售发货单和调拨单是没有word打印模板功能的，需要单独启用

## 解决方案

发货单update vouchers_base set bapplywordtemplate =1 where cardnumber='01'
调拨单update vouchers_base set bapplywordtemplate=1 where cardnumber in (select cardnumber from Vouchers_lang where localeid='zh-cn' and ccardname='调拨单')
