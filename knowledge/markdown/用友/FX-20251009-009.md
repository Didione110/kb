## 问题现象

销售出库单中销售开票数量回写错误

## 问题原因

异常

## 解决方案

开票过程中异常，删除发票后，出库单上数据异常，实际此行出库数量为45000，未开票，现在显示为累计开票主数量-45000，可开票数量90000，导致无法正常重新开票
后台语句修改后正常
update ic_saleout_e set nsignnum = 0 where dr = 0 and cgeneralbid in (select cgeneralbid from ic_saleout_b
where dr = 0 and cgeneralhid in (select cgeneralhid from ic_saleout_h where dr = 0 and vbillcode = 'soo202508260195'));
commit;
