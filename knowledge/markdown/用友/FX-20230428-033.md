## 问题现象

提示字段超长

## 问题原因

字段长度不够

## 解决方案

执行语句：
select 'alter table '+(select name from sysobjects where id=syscolumns.id)+ ' alter column '+name+' nvarchar(300) null',* from syscolumns where name='invoicenums'
and (select name from sysobjects where id=syscolumns.id) like 'T_%'
查出有四条后再执行语句：
alter table T_ExpenseProduct alter column InvoiceNums nvarchar(300) null
alter table T_ApplyMoney alter column InvoiceNums nvarchar(300) null
alter table T_CustMoney alter column InvoiceNums nvarchar(300) null
alter table T_MakeInvoice alter column InvoiceNumS nvarchar(300) null
