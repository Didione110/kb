## 问题现象

凭证作废后无法整理，提示：记-1凭证重号，不能进行凭证整理

## 问题原因

同一期间系统一般不会出现重复凭证号，估计是环境卡顿导致的延迟凭证号起了冲突，软件进行凭证整理的时候又会校验重复凭证号，这就导致了循环错误。

## 解决方案

在数据库执行语句，找到重复的凭证号进行修改，再去系统重新反记账触发，再进行作废整理删除
例：
select * from GL_accvouch where iperiod='7' and iyear='2025' and cdigest='期间损益结转'

select * from GL_accvouch where i_id in ('26843','26844','26845','26846','26847','26848','26849','26850','26851','26852')

update GL_accvouch set ino_id='2' where i_id in ('26843','26844','26845','26846','26847','26848','26849','26850','26851','26852')
