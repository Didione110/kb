## 问题现象

生产订单的单据状态为作废，此时需要删除单据。

## 问题原因

生产订单的单据状态为作废，需要删除单据。此时在系统中是无法继续其他操作或逆操作的。

## 解决方案

需要后台数据库写语句：
select * from mo_mo where docno = '生产订单单号'
update MO_MO set cancel_Canceled=0 where DocNo='订单单号'

 逻辑：先找到需要删除的订单单号，找到后修改此单的状态，修改为核准中，再去系统中删单即可
