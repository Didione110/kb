## 问题现象

每天登录系统打开单据节点都是空白的，重启服务就好了（Oracle11）

## 问题原因

数据库游标未调整

## 解决方案

设置数据库最大游标数量：
SQL>alter system set open_cursors=2000 scope=both;
SQL> alter system set processes = 3000 scope = spfile; #修改连接数
重启服务
