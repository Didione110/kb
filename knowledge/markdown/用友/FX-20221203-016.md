## 问题现象

NC65在辅助余额表中无法过滤出某个客商的余额；客户：cus202112080006，上海塞力斯医学检验实验室有限公司，在集团客户里确定已经分配给了0101业务单元，武汉塞力斯，而在查询辅助余额表时过滤不到此客户相关记录，不过滤查询所有客商时，又能看到此数据；

## 问题原因

前后台客商状态不一致导致；在后台的客商表里，此客户显示停用 3 的状态，修改为启用后正常；

## 解决方案

SELECT * FROM Bd_cust_supplier where code='cus202112080006'
update bd_cust_supplier set custenablestate = 2 where code='cus202112080006'
