## 问题现象

1月薪资已结账，1月的人员调动异常，实际开始日期应该是2025-01-01开始调入新公司，HR调动时写错了时间，为2-1号调动及生效且已执行导致1月社保无法正常在新公司续交；

## 问题原因

操作失误，已执行无法修改且有薪资数据

## 解决方案

后台调整数据：
举例，实际至2024-12-31止他在1008任职，从2025-01-01开始在20300103里任职用户写成了至2025-01-31在1008任职，2025-02-01开始在20300103任职；
1、先在人员档案上确认人员编码，
2、通过人员编码查出PK:
select code, name, pk_psndoc from bd_psndoc where code = 2304001001
得到值1001A610000000001EFR
3、找到旧的任职记录，和新的任职记录，PK_PSNJOB，旧--1001A61000000007W8WL
新--1001A6100000000TNVRS
4、修改时间
新
update hi_psnjob set begindate = '2025-01-01' where pk_psnjob = '1001A6100000000TNVRS'
旧
update hi_psnjob set enddate = '2024-12-31' where pk_psnjob = '1001A61000000007W8WL'
COMMit;
