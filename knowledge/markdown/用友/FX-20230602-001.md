## 问题现象

在凭证生成界面删除了新增的固定资产卡片和计提折旧的凭证，导致在修改新增的固定资产时提示：有后续操作不能修改

## 问题原因

删除后，后台存在缓存，导致提示有后续操作

## 解决方案

"--备份
create table fa_log_0812bak as select * from fa_log;
--表更新
update fa_log set dr = 0 where pk_corp = '公司编码' and code in(select pk_card from fa_card where pk_corp = '公司编码' and dr = 0 and card_code BETWEEN '卡片编码' and '卡片编码');"
