## 问题现象

U8登录提示“strMsg:download 192.168.123.249:4522\Smartclient\UnableInterceptFilesSync.exe'D:\U8SOFT\SmartClient\UnableInterceptFolesSync.exe'error:管道尚未连接“

## 问题原因

u8smartclient和u8smartclientmonitor服务丢失

## 解决方案

1.客户端cmd-输入括号内字段
（SC CREATE U8SmartClient binPath= "\"D:\U8SOFT\U8SmartClient.exe\"" start= auto 
 SC DESCRIPTION U8SmartClient "智能安装服务"
 SC failure U8SmartClient reset= 60 actions= restart/180000

 SC CREATE U8SmartClientMonitor binPath= "\"D:\U8SOFT\U8SmartClientMonitor.exe\"" start= auto 
 SC DESCRIPTION U8SmartClientMonitor "智能安装监控服务"
 SC failure U8SmartClientMonitor reset= 60 actions= restart/180000”），回车
2.计算机服务-找到u8smartclient和u8smartclientmonitor服务，启动即可
