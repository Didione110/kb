## 问题现象

客户档案注册资本字段需要录入美元符号

## 问题原因

客户档案注册资本字段需要录入美元符号

## 解决方案

需要执行以下注册表文件，需要区分32位机器和64位机器，我的电脑属性中可以按到是32位还是64位，添加的特殊字符可以手工编辑。找到字符串键值BadStrException的值里添加需要的特殊字符即可。若没有添加字符串BadStrException也可。

32位机器：Windows Registry Editor Version 5.00注册表[HKEY_LOCAL_MACHINE\SOFTWARE\Ufsoft\WF\V8.700\Portal]”BadStrException”=”<>”\|$”

64位机器：Windows Registry Editor Version 5.00[HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\Ufsoft\WF\V8.700\Portal]”BadStrException”=”<>”\|$”
