## 问题现象

新年度没有做开账结转直接导入凭证，会导致点击总账任何节点提示本年度未开账，但进入系统中的新年度的期初余额节点会显示已开账，开账节点为灰色，且无法结转

## 问题原因

没有进行开账结转操作，直接导入了2022年凭证，系统默认为已开账，实际库表中未开账

## 解决方案

1.备份账套
2.select * from GL_YearState
 update GL_YearState set iOpenFlag='1' where iyear='2022'
 update GL_YearState set iInitFlag='1' where iyear='2022'
3.可以结转，解决
