## 问题现象

oracle数据库中，科情小Q日志表k_prn_sendlog表占用数据库表空间太大，经常死锁

## 问题原因

日志表中LOB（CLOB/BLOB）类型字段删除后空间没释放，表空间被死空间占满了！

## 解决方案

需要先把历史数据归档或删除，然后收缩表空间：
-- 1. 开启行移动
ALTER TABLE K_PRN_SENDLOG_HIS ENABLE ROW MOVEMENT;

-- 2. 收缩表 + 所有LOB + 所有索引（最安全、最有效）
ALTER TABLE K_PRN_SENDLOG_HIS SHRINK SPACE CASCADE;

-- 3. 关闭行移动
ALTER TABLE K_PRN_SENDLOG_HIS DISABLE ROW MOVEMENT;
