## 解决方案

 <div class="login_logo" style="font-size: 23px;">
 <img src="../common/utils/images/123456.png" width="304" height="228" >
 <!-- <%=text.getMessage("company")%> -->
 <%="湖北广济药业济康医药有限公司"%>
 <%="时空智友DHERP系统"%>
 <%if ("true".equals(Configuration.getProperty("demo"))) { %>
 <!-- demo库登录导航 -->
 <%@ include file = "lognavi.jsp" %>
 <%} %>
 </div>

其中div和img的属性 可自行调整 

图片存放路径为： ROOT\common\utils\images
