## 问题原因

oracle数据安装时，勾选了安装容器

## 解决方案

12C如果安装了pdborcl需要启动容器数据库
alter pluggable database pdborcl open ;

--用来查看当前CDB容器中包含的PDB容器
select name,open_mode from v$pdbs; 

SELECT PDB_NAME, STATUS FROM DBA_PDBS;

alter session set container=pdborcl;
