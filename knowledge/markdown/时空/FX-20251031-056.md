## 问题现象

单据在保存时偶尔会出现报“执行服务器端脚本错误....”

## 问题原因

oracle数据库用的12c版本

## 解决方案

数据数中执行：
alter system set result\_cache\_mode=manual;
alter system set result\_cache\_max\_size=0;
alter system set "\_optimizer\_ads\_use\_result\_cache"=false;
