## 问题现象

使用北京提供的最新ROOT配置TOMCAT时，启动时报0RA-28040:没有匹配的验证协议

## 问题原因

数据库环境为19C，版本比较高与TOMCAT存在兼容问题

## 解决方案

1、sqlnet.ora里面增加这两项：
SQLNET.ALLOWED_LOGON_VERSION_SERVER=11
SQLNET.ALLOWED_LOGON_VERSION_CLIENT=11

2、重启数据库，

3、如果开启了可插拔 PDB，额外再打开数据库，如未开启此条忽略
ALTER PLUGGABLE DATABASE orclpdb OPEN;

4、修改用户口令，再改回来：
ALTER USER dherp IDENTIFIED BY dherp1;
ALTER USER dherp IDENTIFIED BY dherp_skzy;
