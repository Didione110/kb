## 问题现象

sql server 2008 R2 维护计划任务提示创建组件失败

## 问题原因

DTS服务未启动

## 解决方案

打开运行（命令提示符）

一、输入 cd c:\windows\syswow64 进入到c:\windows\syswow64路径中

二、输入 regsvr32 "C:\Program Files (x86)\Microsoft SQL Server\100\DTS\Binn\dts.dll"

然后重启数据库服务即可解决
