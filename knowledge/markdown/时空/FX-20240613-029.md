## 问题现象

V10,V11隐藏注册公司名称

## 问题原因

单据再现、基础资料等表单隐藏注册公司名称

## 解决方案

修改位置： ROOT\form\locale\res_zh_CN.js
末尾增加 如下代码：
$(function () {
 var titles = window.document.title.split("-");
 
 if(titles.length > 1) {
 window.document.title = titles[1].trim()
 }
})
