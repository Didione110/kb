## 问题现象

涉及到多机构多部门的企业，操作员在登录的时候，每次都要选机构，一旦机构企业过多，首页显示会非常挤非常丑，不忍直视

## 问题原因

智友自带的页面没人去研究改漂亮一点

## 解决方案

Tomcat\webapps\ROOT\common\verify\js\index.js文件

function autoChange() {
 if (!needVerify) {
 $("#litorg").css("height", "500px");
 $("#litorg").css("max-height", "500px");
 }
}

新增max-height属性，拉高页面显示
建议手里客户是连锁或者多机构的批发的时候注意看看
