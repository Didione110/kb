## 问题现象

工单系统使用el-image引用图片加载失败

## 问题原因

使用require字段引用图片报错，vue3\+vite构建的项目不能使用require，只能用import

## 解决方案

使用import引入图片路径：资源可使用import.meta.globEager(“…/\*.png”) ;
动态引入，需要给 css 路径加括号，vite官网静态资源处理 new URL(url, import.meta.url)
