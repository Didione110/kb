## 问题现象

升级后升级前的表单流程处理人意见区数据丢失

## 问题原因

升级后意见表 新增的属性 VIEW_GROUP_ID、GROUP_ID 为空导致意见没有查询出来，默认值是0

## 解决方案

数据修复：
-- 1、执行sql前自行做好数据库备份，非常重要！！！

-- 2、查询问题数据量

select count(*) from ctp_comment_all where VIEW_GROUP_ID is null;
select count(*) from ctp_comment_all where GROUP_ID is null;
-- 3、修复数据

update ctp_comment_all set VIEW_GROUP_ID=0 where VIEW_GROUP_ID is null;
update ctp_comment_all set GROUP_ID=0 where GROUP_ID is null;
