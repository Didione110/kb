## 问题现象

组织架构调整，部门删除新增后，导致预算费控单子提示部门无对应预算问题

## 问题原因

主要是原部门预算还没调整，OA组织架构上就操作了部门新增删除，导致后面再做调整时，选不到原部门

## 解决方案

后台进行删除部门的恢复，同时强调，使用了c4费控的话，如果部门涉及调整的，一定考虑预算调整后，再进行相关OA组织架构的变动
相关部门恢复语句如下：
select * from org_unit where name = 'xxx'
UPDATE ORG_UNIT set IS_DELETED=0,IS_ENABLE=1 where id ='4692014745050303066';
