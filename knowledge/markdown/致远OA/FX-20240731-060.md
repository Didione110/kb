## 问题现象

想获取每条协同事项的接收人、接收时间、首次阅读时间、处理时长、是否超期、超期时长、待办还是已办、是否超期等信息

## 问题原因

系统无自带报表

## 解决方案

SQL参考如下：

-- SQL语法：MySQL，其它数据库可能无法运行，请自行调整
SELECT
 c.id '流程ID',
 c.create\_date '发起时间',
 a.sender\_id '发起人MemberID',
 a.member\_id '接收人MemberID',
 a.COMPLETE\_TIME '处理时间',
 a.run\_worktime '处理时长-分钟',
 a.FIRSTVIEW\_PERIOD '首次阅读正文时间-单位毫秒',
 a.NODE\_POLICY '节点权限',
 a.RECEIVE\_TIME '收到时间',
 a.DEADLINE\_DATE '处理期限',
 a.OVER\_TIME '超期时长-按自然时间计算',
 case 
 when a.STATE = 3 then '待办'
 else '已办' end as '处理状态',
 case
 when a.IS\_COVER\_TIME = 0 then '否'
 else '是' end as '是否超期'
 FROM
 COL\_SUMMARY c
 LEFT JOIN ctp\_affair a on
 c.id = a.OBJECT\_ID
 WHERE
 c.CASE\_ID IS NOT NULL 
 AND c.PROCESS\_ID IS NOT NULL 
 AND c.TEMPLETE\_ID IS NULL -- TEMPLETE\_ID is not null表示获取流程表单的数据；TEMPLETE\_ID is null表示获取自由协同的数据
 AND c.create\_date BETWEEN '2024-01-01 00:00:00' and '2025-06-30 23:59:59' -- create\_date表示流程发起时间范围，自行根据时间调整
 ORDER BY c.create\_date
