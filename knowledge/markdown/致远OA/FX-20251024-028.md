## 问题现象

如何查看流程图模板修改的历史信息

## 问题原因

平台当前不支持通过界面查看流程图模板的历史版本，但相关数据已在数据库中保存。可通过直接查询数据库，获取流程图的历史版本信息，用于恢复或问题分析。

## 解决方案

wf_process_templete 主流程模板表
wf_templete_shadow_xml 存储流程图历史版本
关联关系：
wf_templete_shadow_xml.main_template_id = wf_process_templete.id
查询流程图历史版本
SQL 查询语句
SELECT
 t.id,
 s.id AS sId,
 t.processname,
 s.workflow,
 s.create_time
FROM
 wf_process_templete t
LEFT JOIN wf_templete_shadow_xml s ON s.main_template_id = t.id
WHERE
 t.id = '@processtemplateid'
ORDER BY
 s.create_time DESC;
参数说明
字段名 含义
id 流程模板ID
processname 流程模板名称
workflow 流程图数据（XML 格式）
create_time 历史版本创建时间
sId 历史版本记录ID（用于回滚）
获取sid可参考附件
如需将流程图恢复到某个历史版本，可使用以下 SQL：

UPDATE wf_process_templete
SET
 workflow = (SELECT workflow FROM wf_templete_shadow_xml WHERE id = '@sId'),
 shadow_xml_id = '@sId'
WHERE
 id = '@processtemplateid';
⚠️ 注意：

@sId 为上一步查询结果中对应历史版本的 sId
执行前建议备份当前流程图数据
