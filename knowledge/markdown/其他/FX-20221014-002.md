## 问题现象

账套启用了多币种管理，在【基础设置】-【科目】中无法启用外币核算，勾选框为灰色无法启用

## 问题原因

数据异常，后台语句处理将科目表中是否外币核算值改为true

## 解决方案

备份账套数据，执行脚本update AA\_Account set isexchange='1'WHERE CODE ='科目编码'AND accountingyear=需要修改科目年份
