## 问题现象

B2B电商订单数据推送ERP后，客户在电商上申请退款了，后面订单还是开票发货了

## 问题原因

电商前台申请退货退款取消后，退货退款数据会推送到退货退款中间表。但是没有改变原订单数据状态

## 解决方案

B2B电商订单数据推送ERP后，在还未开票前，客户在电商上申请退款后需及时取消ERP内订单，避免订单进入ERP线下流程。在退货退款中间表上添加触发器，当有退货退款数据过来后关联订单中间表数据，订单如果还是已受理未开票的状态，更新订单状态成已取消。停止订单流程

create TRIGGER \[dbo\].\[b2b\_state\_update\] 
 ON \[dbo\].\[b2b\_returnGoods\_hz\]
 for INSERT,update 
AS 
BEGIN
```
 update a set a.orderstate='已取消' from b2b_ds_orderhz a join inserted b on a.ORDERNUM=b.ordernum 

```

where a.ORDERSTATE='已受理'

END
