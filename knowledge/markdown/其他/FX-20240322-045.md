## 问题现象

pos端结算时提示日期不在账期内

## 问题原因

T\+端会计期间不是以1月份开始， 排查启用期间2023.4实际对应的启用日期是2023年8月

## 解决方案

1. 在T\+服务器数据库执行
```
 SELECT * From EAP_AccInformation Where Name = 'Retail'（从选项表查询选项名称为零售的所有信息，以此来查出零售的会计期间）
 select * from SM_Period where id='40'（从会计期间表查出主键为40的所有信息）
 排查启用期间2023.4实际对应的启用日期是2023年8月
 update EAP_AccInformation set idEnablePeriod='36' Where Name = 'Retail'（在选项表中修改零售的启用期间id为36）
 2.在POS端数据库执行
 （1）pos数据库新建查询方法:打开数据库管理工具pgAdmin IIl
 连接PostaresOL 9.5(x86)(locahost:5432)，录入密码tplus_12345
 点击数据库-postgres，上方工具栏点击执行任意的sql查询
 （2） SELECT min(begindate), max(enddate) FROM sm_period WHERE bizterminalstate =' 0' And begindate >= (SELECT begindate From sm_period Where id = (SELECT idEnablePeriod From EAP_AccInformation Where Name = 'Retail') )
 在会计期间表中查询业务结账状态为否且开始时间大于等于选项表中选项名称为零售的启用ID的最小开始时间和最大结束时间。查出最小开始时间为8月
 update EAP_AccInformation set idenableperiod='36' Where Name = 'Retail'
 修改启用期间，重启服务，pos测试解决

```
