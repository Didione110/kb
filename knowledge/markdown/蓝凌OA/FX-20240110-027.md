## 问题现象

根据身份证号码获取性别以及出生日期

## 问题原因

蓝凌无标准公式可以设置，需要代码解决

## 解决方案

先将性别以及出生日期改成公式加载控件，加载方式勾选为自动加载以及控件加载，经测试单行文本控件会报错，代码如下：
出生日期：
import java.text.SimpleDateFormat; 
import java.util.Date; 
String x=$身份证号$;//根据项目自行替换
 String a=x.substring(6,14);
 SimpleDateFormat sdf = new SimpleDateFormat("yyyyMMdd");
 Date date= null;
 try {
 date = sdf.parse(a);
 } catch (ParseException e) {
 }
 sdf = new SimpleDateFormat("yyyy-MM-dd");
 return sdf.format(date);

性别：
String idCardNumber = $身份证号$;//根据项目自行替换
String genderCode = idCardNumber.substring(16, 17);
if (Integer.parseInt(genderCode) % 2 == 0) {
 return "女";
 } else {
 return "男";
}
