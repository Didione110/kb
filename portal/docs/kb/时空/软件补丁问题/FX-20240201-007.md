## 问题现象

DHERP更新模块，无报错，但是更新后，新功能及设置项都未生效

## 问题原因

原始模块比较早，更新模块时，实际后台报错已截断

## 解决方案

执行以下脚本再更新模块

alter table formdoc add lastmodifytime char(19)

alter table formdoc add updater nvarchar(80)
ALTER TABLE ProcList ADD SortNum int NULL DEFAULT 0;

DELETE FROM TbStru WHERE upper(TbName) = 'PROCLIST' AND upper(FdName) = 'SORTNUM';
INSERT INTO TbStru (TbName, SortNum, FdName, FdDesc, Is_Null, DefaultValue, Explains, IsDevFld) 
 VALUES ('ProcList', 11, 'SortNum', '序号', 'Y', '0', '', 'N');

 ALTER TABLE Funclist ADD Updater nvarchar(80) NULL DEFAULT '';

DELETE FROM TbStru WHERE upper(TbName) = 'FUNCLIST' AND upper(FdName) = 'UPDATER';
INSERT INTO TbStru (TbName, SortNum, FdName, FdDesc, Is_Null, DefaultValue, Explains, IsDevFld) 
 VALUES ('Funclist', 19, 'Updater', '更新人', 'Y', '', '', 'N');

再次更新时RM导入成功后，再次更新供应链能够看到进度提示
