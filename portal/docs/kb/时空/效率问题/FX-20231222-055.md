## 问题现象

SQL效率太低，对应有索引，但是没有执行索引

## 问题原因

SQL效率太低，对应有索引，但是没有执行索引，有可能索引无效。

## 解决方案

1.可以删除索引，再进行重建索引
 drop index idx_yh_r3505t_st ;
 create index idx_yh_r3505t_st on k_yinhai_rpt3505_t(sel_retn_time) online;

2.也可以进行直接重建，不用删除，
alter index idx_yh_r3505t_st rebuild online;
说明： rebuild online 方式比较快，可以在24*7环境中实现，建议使用此方式。
