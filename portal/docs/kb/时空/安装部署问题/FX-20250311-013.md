## 问题现象

sql数据库收缩报错

## 问题原因

数据库文件有损坏

## 解决方案

1.检查数据库的完整性：DBCC CHECKDB ('数据库名') WITH NO_INFOMSGS;
如果发现有损坏：
2.将数据库改为单用户模式ALTER DATABASE [数据库名] SET SINGLE_USER WITH ROLLBACK IMMEDIATE；
3.修复：DBCC CHECKDB ('数据库名', REPAIR_ALLOW_DATA_LOSS);
4.将数据库还原回多用户模式：ALTER DATABASE [数据库名] SET MULTI_USER;
再右键数据库收缩成功
