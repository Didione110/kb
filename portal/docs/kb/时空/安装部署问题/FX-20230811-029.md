## 问题现象

使用oracle12c部署的时空在通过前台导入大量数据时可能会出现如下报错
ORA-00600: 内部错误代码, 参数: [kpp_concatq:2], [12], [11], [0], [], [], [], [], [], [], [], []
常见于助记码生成,库存导入,资料修改审批等场景数据量较大的情况中

## 问题原因

官方建议是重建表可以解决,根据判断是NVARCHAR2与varchar2转换中文时字符集问题导致缓存出错,但是相关补丁页面无法访问

## 解决方案

1.方案一:在通过update等方式将NVarchar2 字段的内容写入Varchar2时会触发该问题,解决方法是将 数据库表中对应的NVarchar2字段转为Varchar2再进行执行,或执行语句行进行to_char转换以后在进行插入
2.方案二:无法定位或者字段无法更改的情况下,可以用过关闭result cache解决
sqlplus用户下执行如下命令,关闭result cache缓存,暂时未发现其他影响
alter system set result_cache_mode=manual;
alter system set result_cache_max_size=0;
alter system set "_optimizer_ads_use_result_cache"=false;

以上两种方法都可以解决,可以按实际项目情况进行选择
