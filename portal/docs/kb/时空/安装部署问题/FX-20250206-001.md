## 问题现象

DHERP登录界面信息“ 数据港云商管理系统 DHERP ”和LOGO 修改为客户的

## 问题原因

DHERP登录界面信息“ 数据港云商管理系统 DHERP ”和LOGO 修改为客户的

## 解决方案

ROOT 下面的 login.jsp 查找 lognavi.jsp 修改如下这段

 &lt;div class="login_logo" style="font-size: 23px;"&gt;
 &lt;img src="../common/utils/images/123456.png" width="304" height="228" &gt;
 &lt;!-- &lt;%=text.getMessage("company")%&gt; --&gt;
 &lt;%="湖北广济药业济康医药有限公司"%&gt;
 &lt;%="时空智友DHERP系统"%&gt;
 &lt;%if ("true".equals(Configuration.getProperty("demo"))) &#123; %&gt;
 &lt;!-- demo库登录导航 --&gt;
 &lt;%@ include file = "lognavi.jsp" %&gt;
 &lt;%&#125; %&gt;
 &lt;/div&gt;

其中div和img的属性 可自行调整 

图片存放路径为： ROOT\common\utils\images
