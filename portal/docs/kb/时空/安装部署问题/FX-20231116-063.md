## 问题现象

DHERP注册提示报错：beyondthe date limits

## 问题原因

DHERP，更换注册服务器操作后

## 解决方案

1. 找北京将对应产品号注册重置
2. 之前使用的tomcat也需要关闭
3. 新服务器tomcat下对应数据库，清除了下面内容，

select \* from ModuleAccrt
select \* from FuncAccredit
select \* from ProductAccrt
select \* from sysstate，
4. 新服务器tomcat文件夹缓存清除
5. 确保ROOT版本是新版本
6. 然后重启tomcat，进行注册
