## 问题现象

SQL Server2019 登录错误 18456 (用户 'sa' 登录失败),sa账户无法远程连接

## 问题原因

错误 18456 表示 SQL Server 拒绝了登录请求，可能的原因包括：
用户名或密码不正确
账户被禁用
SQL Server 身份验证模式未启用
账户被锁定

## 解决方案

-- 检查 sa 账户状态
SELECT name, is_disabled FROM sys.server_principals WHERE name = 'sa'

-- 如果被禁用，启用账户
ALTER LOGIN sa ENABLE;

-- 如果被锁定，解锁账户
ALTER LOGIN sa WITH PASSWORD = '现有密码' UNLOCK;
