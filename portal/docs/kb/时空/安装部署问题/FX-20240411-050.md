## 问题现象

Oracle12c安装出现Failed to Create oracle Oracle Home User的解决方案

## 问题原因

由于建立密码过于简单导致无法进行创建成功

## 解决方案

1、打开域安全策略（secpol.msc）-安全设置-账户策略-密码策略-密码必须符合复杂性要求。定义这个策略设置为:已禁用。

2、最后cmd运行刷新组策略命令为：gpupdate /force

3、重新安装。

4、解决。
