## 问题现象

时空中，如果存在0金额的出库单，在发票登记中是无法记录的，同时金税接口也无法开具0金额的出库单。
但是财务系统做账时，是按发票进行成本结转，故这部分的数据则需要进行成本结转登记发票记录

## 问题原因

单独开发SQL存储过程，对这部分的数据进行集中处理，让其可以生成发票数据，从而实现成本结转
1:查询到满足条件的结果集合
2：根据结果集合来生成对应的循环
3：对0金额的单据循环生成发票表数据
4：回写出库单发票状态

 SELECT ROW_NUMBER() OVER ( ORDER BY a.BillNo ) AS now_sn , a.BillNo AS now_billno , a.BillCode AS now_billcode
 INTO #No1_Needlist
 FROM dbo.SALEOUTMT a
 WHERE a.IsInvoice = 'N'
 AND a.TaxAmount = 0
 AND ( SELECT COUNT (1) FROM dbo.SALEOUTDT b WHERE a.BillNo = b.BillNo
 AND b.IsInvoice = 'Y' ) = 0
 ORDER BY a.BillNo

 DECLARE @No1_Needlist_count INT
 SET @No1_Needlist_count = ( SELECT COUNT (1) FROM #No1_Needlist );
