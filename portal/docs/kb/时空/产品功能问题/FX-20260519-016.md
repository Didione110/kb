## 问题现象

采购退出出库单冲红，应该是增加库存的操作，却提示负库存

## 问题原因

原因是提取出来的数量没问题，但基本数量除了第一行没有问题，后面行中【基本数量】都不等于【数量】，如图

## 解决方案

检查冲红调用脚本其中一段：
for(var i=0;i&lt;ds_ddmx.recordCount;i++)&#123;
 await ds_ddmx.setPos(i);
 return await pf_fieldCompute(ds_ddmx,"num","",1);
&#125;
以上为原代码，存在bug：
return 写在循环里，第一次循环就直接退出，后面的行完全不处理，所以造成后面行中【基本数量】都不等于【数量】的情况，要循环处理每一行，不能把 return 放在循环里面，pf_fieldCompute 是计算函数，逐行调用才会生效，去除return
