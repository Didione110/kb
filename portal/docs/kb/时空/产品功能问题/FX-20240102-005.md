## 问题现象

PDA上架时，如果返回报错，会提示商品已经上架，无法重新上架(ORACLE)

## 问题原因

WMS存储过程上架临时表已经回写数据(ORACLE)

## 解决方案

存储过程 WMS_PDA_RQSJ(ORACLE)
if nvl(v_error_msg,' ') != ' ' then 
 v_error_msg := v_error_msg || '和品种的大类不一致!';
 
 --update StoreRoom set beactive = 'Y' where beactive ='Z';
 
 RAISE_APPLICATION_ERROR(-20123, v_error_msg);
 return ;
 end if;
把报错拦截从调用类型 B2调至 B1
