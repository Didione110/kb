## 问题现象

付款，收款，明细回写不全，结算金额正确

## 问题原因

付款，收款结算时，明细回写时，将多条明细的金额回写到其中一条上，但整单结算金额正确，导致明细回写不对

## 解决方案

if (dftje*1 &gt; 0) &#123;
 if (dftje*1 &gt;= wftje*1) &#123;
 ds_dftmx.setValueAt(j, "jiesje", wftje);
 ds_dftmx.setValueAt(j, "issettle", "Y");
 
 dftje = Utility.formatFloat(dftje - wftje, 2);
 
 &#125; else &#123;
 ds_dftmx.setValueAt(j, "jiesje", dftje);
 dftje = 0;
 &#125;
 &#125; else &#123;

 &#125; else &#123;
