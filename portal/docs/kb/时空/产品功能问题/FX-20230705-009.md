## 问题现象

销售出库退回不了，提示超过原单数量，而实际并没有超

## 问题原因

销售退回通知单保存后，回写出库单已退回数量，如果进行单据调整几次，回写数量就会翻几倍，导致数据错乱

## 解决方案

单据调整时，将调整单的数量记录下来，并保存前回写这个单子已退数量。
function before_save() &#123;
var sqlList = [];
sqlList[sqlList.length] = "update saleoutdt set k_returnnum=k_returnNum - returnNum where billno=" + rebillno +"";
DBUtil.batchUpdate(sqlList);
