## 问题现象

sa账户登录失败，管理员无法将该账户进行解锁

## 问题原因

sql 库在短时间内不停被连接或者密码错误多次，触发锁定保护机制了

## 解决方案

ALTER LOGIN sa ENABLE ;

GO

ALTER LOGIN sa WITH PASSWORD = '123456' unlock, check_policy = off,

check_expiration = off ;

用windows 账户登录进去执行该语句解锁
