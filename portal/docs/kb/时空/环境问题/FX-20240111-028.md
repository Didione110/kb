## 问题现象

客户反馈系统单据时间与本地时间隔4分钟

## 问题原因

应用服务器的电脑时间未联网，有延时，

## 解决方案

服务器为centos系统，按如下命令调整时间
date //查看系统时间

hwclock //查看硬件时间 

yum -y install utp ntpdate //安装utpdate工具

ntpdate cn.pool.ntp.org //设置系统时间与网络时间同步

hwclock --systohc //将系统时间写入硬件时间 (如硬件时间本身无问题可以不处理此条)
