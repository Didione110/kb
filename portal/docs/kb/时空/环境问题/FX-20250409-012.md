# mssql2008的数据库中毒损坏，只保留了mdf文件，无ldf文件，直接还原报错One or more files do not match the primary file of the database. If you are attempting to attach a database, retry the operation with the correct files. If this is an existing database, the file may be corrupted and should be restored from a backup.
文件激活失败。物理文件名称'D:\mssql2008\data\race_log.LDF'可能不正确。
无法重新生成日志，原因是数据库关闭时存在打开的事务/用户，该数据库没有检查点或者该数据库是只读的。如果事务日志文件被手动删除或者由于硬件或环境问题而丢失，则可能出现此错误。

## 问题现象

mssql2008的数据库中毒损坏，只保留了mdf文件，无ldf文件，直接还原报错One or more files do not match the primary file of the database. If you are attempting to attach a database, retry the operation with the correct files. If this is an existing database, the file may be corrupted and should be restored from a backup.
文件激活失败。物理文件名称'D:\mssql2008\data\race_log.LDF'可能不正确。
无法重新生成日志，原因是数据库关闭时存在打开的事务/用户，该数据库没有检查点或者该数据库是只读的。如果事务日志文件被手动删除或者由于硬件或环境问题而丢失，则可能出现此错误。

## 问题原因

原因是数据库关闭时存在打开的事务/用户，该数据库没有检查点或者该数据库是只读的。如果事务日志文件被手动删除或者由于硬件或环境问题而丢失，则可能出现此错误。

## 解决方案

通过紧急模式重建日志‌

‌新建同名空数据库‌：
sql
Copy Code
CREATE DATABASE race; 
‌停止SQL Server服务‌：
打开“服务”管理器（services.msc） → 停止SQL Server (MSSQLSERVER)服务。
‌替换物理文件‌：
删除新建的race.mdf和race_log.ldf文件。
将原race.mdf文件复制到D:\mssql2008\data\目录。
‌重启SQL Server服务‌，并执行以下命令：
sql
Copy Code
ALTER DATABASE race SET EMERGENCY; 
ALTER DATABASE race SET SINGLE_USER WITH ROLLBACK IMMEDIATE; 
ALTER DATABASE race REBUILD LOG ON (NAME = race_log, FILENAME = 'D:\mssql2008\data\race_log.ldf'); 
ALTER DATABASE race SET MULTI_USER; 
ALTER DATABASE race SET ONLINE; 
‌注意‌：
若提示“文件访问被拒绝”，检查权限设置‌ 。
若路径含空格或特殊字符，需用单引号包裹路径‌
