## 问题现象

客户sql数据库使用一段时间后，日志文件变大，且通过备份、压缩等方式无法减小

## 问题原因

采用语句执行

## 解决方案

--查询指定数据库的日志文件名称
 USE [ksoa] 
GO 
SELECT name FROM SYS.database_files WHERE type_desc='LOG' 
数据库压缩 
USE [master]
 GO 
ALTER DATABASE [ksoa] 
SET RECOVERY SIMPLE WITH NO_WAIT 
GO 
ALTER DATABASE [ksoa] SET RECOVERY SIMPLE 
GO 

USE [ksoa] 
GO 
DBCC SHRINKFILE (N'ksoa_zuizhong_Log' , 0,TRUNCATEONLY) 
GO 

USE [master]
 GO 
ALTER DATABASE [ksoa] SET RECOVERY FULL WITH NO_WAIT
 GO 
ALTER DATABASE [ksoa] SET RECOVERY FULL 
GO
