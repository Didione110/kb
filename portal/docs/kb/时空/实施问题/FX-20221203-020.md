## 问题原因

客户提供相关资料可能存在中文与数字列在一起的情况，而我们需要分开成两个字段，比如银行账号，客户可能会将开户行与账号整到一列中

## 解决方案

创建一个字符串中提取数字的标量值函数，如下：
CREATE function [dbo].[GetNumber](@str nvarchar(500))
 returns varchar(max)
as
begin
 while patindex('%[^0-9]%',@str)&gt;0
 begin
 set @str=stuff(@str,patindex('%[^0-9]%',@str),1,'')
 end
 return convert(VARCHAR(max),@str)
end
GO
