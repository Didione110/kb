## 解决方案

user_objects 包含所有用户下的表、视图、存储过程，
1、找到你要内容
sELECT object_name, created,object_type, status FROM user_objects WHERE object_type = 'PROCEDURE'
and object_name like 'WMS%'
2、查到对应代码内容
SELECT text FROM user_source WHERE name ='WMS_PDA_RECE' AND type ='PROCEDURE'
ORDER BY line;
