## 问题现象

使用加权平均计价方式：
1.商品结存初装新增0数量商品批号数据，默认storbalance表新生成的cost为0，若后期做销售退回时，会造成成本为0
2.在storbalance商品库存为0，赠品入库时，storbalance表的cost不会修改为0，默认还是最后记录的cost，若后期做销售出库时，会造成成本不为0出库

## 问题原因

使用加权平均，成本规则有误

 UPDATE storbalance sb
SET sb.cost = 
 CASE 
 WHEN sb.stornum &lt;&gt; 0 THEN sb.storamount / sb.stornum 
 ELSE sb.cost 
 END
WHERE EXISTS (
 SELECT 1 
 FROM purindt pi 
 WHERE pi.whid = sb.whid
