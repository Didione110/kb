## 问题现象

oracle数据库版本的时空查询数据时提示：ORA-01792:表或视图中的最大列数为1000

## 问题原因

查询时，当查询的列没有达到1000，但是关联的表过多，关联表的总列数超过了1000的话，会报上面的错误。

## 解决方案

用SysDba登录，执行以下这句话就可解决：alter system set "_fix_control"='17376322:OFF';
