## 问题现象

销售出库赠品后，做销售退回，在销售退回入库单保存时提示成本不能为0

## 问题原因

未取到成本系统拦截无法入库

## 解决方案

在销售退回入库单明细数据集新增字段cost1,服务端among_save()里面修改拦截代码为：
if(parseFloat(ds_ddmx.getValueAt(i, "cost1"))&lt;0.000001)&#123;
 if (parseFloat(ds_ddmx.getValueAt(i, "cost"))&lt;=0.0000001 && ds_ddmx.getValueAt(i, "IsFree").equals("N"))&#123;
 Utility.throwError("行["+ (i+1) +"]：["+ds_ddmx.getValueAt(i, "goodsname")+"] 未取到成本，请先进行初装！");
 &#125;
 &#125;
对于赠品出库后销售退回无法保存的情况，在明细数据集新增的字段cost1里面填写大于0.000001的数字即可保存
