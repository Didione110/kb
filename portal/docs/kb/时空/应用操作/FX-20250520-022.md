## 解决方案

​​方法 1：使用 Edge 的 IE 模式（推荐）​​
Edge 的 ​​IE 模式​​ 可以让网页在 Edge 内部以 ​​IE 渲染引擎​​ 运行，适用于需要 ActiveX 或旧版 IE 特性的网站。

​​步骤：​​
​​打开 Edge 浏览器​​，访问需要兼容的网站（如 http://localhost 或内网地址）。
点击右上角的 ​​⋮（三点菜单）​​ → ​​“更多工具”​​ → ​​“在 IE 模式下重新加载”​​（如果该选项可用）。
​​如果看不到该选项​​，继续下一步手动添加。
​​手动添加 IE 模式网站​​：
点击 ​​⋮（三点菜单）​​ → ​​“设置”​​ → ​​“默认浏览器”​​ → ​​“允许在 Internet Explorer 模式下重新加载站点”​​。
点击 ​​“添加”​​，输入需要兼容的网站地址（如 http://localhost 或 http://192.168.x.x）。
点击 ​​“添加”​​ 完成。
刷新页面，Edge 会自动以 ​​IE 模式​​ 加载该网站
