## 问题现象

有些客户在实施完诺诺发票后，希望给客户或者业务员发送邮件，目前的诺诺接口是支持利用诺诺的sass发送发票邮件，但是因为是sass标准化产品，所以不能在邮件里自定义内容

## 问题原因

但是因为是sass标准化产品，所以不能在邮件里自定义内容

## 解决方案

用发散思维，其实可以自行部署SMTP邮件服务 ，如果是MSSQL数据库是支持SMTP协议的，于是乎我就编写了一份语句，提供大家参考，延伸开来其实可以应用于其他多种业务场景，如：采购付款申请做了后邮件通知审批人？发票开完后邮件通知客户？首营做完后邮件通知质管？快递发完后邮件通知收货人？等等

 DECLARE @body VARCHAR(500)
 DECLARE @subject VARCHAR(500)
 DECLARE @recipients VARCHAR(500)
 SET @body = ( SELECT TOP 1
 '你好，当前发送：' + a.buyerName + '的发票,发票号：' + CAST(a.invoiceNo AS VARCHAR(30)) + '，开票日期' + a.invoiceDate + ',开票含税金额：'
 + CAST(a.orderAmount AS VARCHAR(50)) + ' ,发票下载地址：' + a.pdfUrl
 FROM v_nn_invoice a
 WHERE a.orderNo = 'SCK2024030800678-bs--20240309170318366-001'
 AND a.invoiceNo = '24422000000018027740' )
 SET @subject = ( SELECT TOP 1
 '你好，当前发送：' + a.buyerName + '的发票,发票号：' + CAST(a.invoiceNo AS VARCHAR(30))
 FROM v_nn_invoice a
 WHERE a.orderNo = 'SCK2024030800678-bs--20240309170318366-001'
 AND a.invoiceNo = '24422000000018027740' )
 SET @recipients = '50534205@qq.com'
 
 
 EXEC [msdb].[dbo].[sp_send_dbmail] @profile_name = 'race_mail' --这里和定义的配置需要相同
 , @recipients = @recipients , @body = @body , @subject = @subject
