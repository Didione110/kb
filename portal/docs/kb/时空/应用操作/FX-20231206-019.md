SQL判断是否数字

## 解决方案

--返回0-则为纯数字(支持正负数，小数点)
 SELECT PATINDEX('%[^0-9|.|-|+]%','2.2')--返回0

 --返回0-则为纯整数
select PATINDEX('%[^0-9]%', '2.2')--返回非0
