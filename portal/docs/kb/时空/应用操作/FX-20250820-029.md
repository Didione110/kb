## 问题现象

同一单据使用同一打印模板需要打印出两套内容，打印后系统自带页码不会重新计算，同时只希望部分单位打印两套模板

## 问题原因

打印后系统自带页码不会重新计算

## 解决方案

在代码区配置参考如下
var page1_Current: Integer;
var page1_Total: Integer;
var page2_Current: Integer;
var page2_Total: Integer;
var i: Integer;

procedure Page1OnBeforePrint(Sender: TfrxComponent);
begin
 SetID(&lt;dshz."单据ID"&gt;,'0kxiupl34pb60z4m','4szcn61oa8b0tz79');
 if not Engine.FinalPass then
 begin
 page1_Current := page1_Current + 1;
 end;
end;

procedure Page2OnBeforePrint(Sender: TfrxComponent);
begin
 if (&lt;dshz."单位名称"&gt; &lt;&gt; '康笙园智慧药房（武汉）有限公司') and
 (&lt;dshz."单位名称"&gt; &lt;&gt; '康笙园大药房（沈阳）有限公司') and
 (&lt;dshz."单位名称"&gt; &lt;&gt; '赤壁市蒲圻办事处莼川社区卫生服务中心（赤壁市第二人民医院）') then
 page2.Visible := False

 else
 page2.Visible := True;
 if not Engine.FinalPass then
 begin
 page2_Current := page2_Current + 1;

 end;

end;

procedure Memo50OnBeforePrint(Sender: TfrxComponent);
begin
 if not Engine.FinalPass then
 begin
 Page1_Total := Page1_Total+1 ;
 end;
end;

procedure Memo74OnBeforePrint(Sender: TfrxComponent);
begin
 if not Engine.FinalPass then
 begin
 Page2_Total := Page2_Total+1 ;
 end;
end;

begin

end.

同时需要再设置打印业务的配置地方修改为
第[Page#]页/共[Page1_Total]页

第[&lt;Page#&gt;-&lt;Page1_Total&gt;]页/共[Page2_Total]页

即可实现效果，项目具体调整
