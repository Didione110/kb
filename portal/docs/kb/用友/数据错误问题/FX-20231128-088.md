## 问题现象

弃审调差补料单提示报错：有后续的单子，但是联查后续的单子已经删除完成了

## 问题原因

后台应该卡数据了，导致虽然没有材料出库单，但是看备料计划上有累计出库数量

## 解决方案

查看备料计划单，没有后续出库，但是有累计出库数量，在数据库清空累计出库数量update mm_pickm_b set ljcksl = 0 where pk_pickmid = '1002F8100000002F3IW9'
