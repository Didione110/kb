## 问题现象

有欠款不允许离职

## 问题原因

产品逻辑校验

## 解决方案

1、建议先做还款单，完成后再做离职
2、条件1实在无法做到时，又必须要做人员离职，可用后台语句处理：
执行脚本前做好数据备份工作
该校验在业务插件中，需要停用这个业务插件在进行离职，等离职之后再启用这个业务插件。注意业务场景是有缓存，执行脚本之后要重启服务，停用脚本执行之后重启服务，离职好之后，再执行启用的脚本，再重启服务。脚本见附件。

--停用校验的插件
update pub_eventlistener set enabled = 'N' where implclassname = 'nc.bs.erm.eventlistener.PsnDimissionJkValidateListener';
commit;
--启用校验的插件
update pub_eventlistener set enabled = 'Y' where implclassname = 'nc.bs.erm.eventlistener.PsnDimissionJkValidateListener';
commit;
