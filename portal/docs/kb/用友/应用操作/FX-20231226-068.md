## 问题现象

信贷管理期初合同已关闭不能直接删除

## 问题原因

产品默认执行之后，正常是先撤回执行情况，但是目前补录期初，无法判断是手工录入的，还是系统执行的，在执行情况界面删不掉。

## 解决方案

更改执行情况
--备份（SQL数据库）
select * into fi_contract_run_bak20231219 from fi_contract_run;
--备份（ORACLE数据库）
createtablefi_contract_run_bak20231219asselectfromfi_contract_run;
--查看备份的表selectfrom fi_contract_run_bak20231219;
--查询对应的合同取得合同主键pk_id记作aaa
select * from fi_cont_main where code='123（合同号）';
--前述查询到的pk_id记作aaa--删除对应合同的执行情况
delete from fi_contract_run where pk_parent='1071F8100000000001Q5（查询的主键）'

更改合同状态
--beifen
select * into fi_contract_bak20231219 from fi_contract;
