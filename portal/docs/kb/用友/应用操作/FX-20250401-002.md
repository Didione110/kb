## 解决方案

21年发货单20211208025，出库未开票；出库202112090016，订单21120205
update dispatchlist set bsaleoutcreatebill='0' where cdlcode='20211208025'
DispatchList发货退货单主表，bsaleoutcreatebill 是否出库开票 
显示的1，改为0后正常参照出发货单
