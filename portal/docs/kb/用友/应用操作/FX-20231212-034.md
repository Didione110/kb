## 问题现象

修改供应商名称，一直提示“发展日期是默认值，不可为空!”但是发展日期是灰色的，无法填写

## 问题原因

可能是T3升级U8自带的BUG

## 解决方案

数据库执行select dVenDevDate from vendor where cVenCode='GS0031'查出供应商发展日期为空，update vendor set dVenDevDate='2023-03-01 00:00:00.000' where cVenCode='GS0031'填充发展日期，回U8软件中修改供应商名称，解决
