# 1.费控单据-预付发票核销单据 生成凭证默认是 借：费用科目 贷：银行科目，科目对照表设置的费用科目都没有带供应商辅助核算（费用会计科目上没有供应商辅助） 2.但是客户想实现在生成总账凭证将 费用科目改成预付科目，预付科目是带了供应商辅助的，客户改完科目后发现无法选择供应商辅助 3.添加了费用报销单和预付发票核销事项分录的模板，加上了供应商业务关联（预付发票核销单据上费用分摊区有供应商） 但是生成业务事项还是报错供应商错误

## 问题现象

1.费控单据-预付发票核销单据 生成凭证默认是 借：费用科目 贷：银行科目，科目对照表设置的费用科目都没有带供应商辅助核算（费用会计科目上没有供应商辅助） 2.但是客户想实现在生成总账凭证将 费用科目改成预付科目，预付科目是带了供应商辅助的，客户改完科目后发现无法选择供应商辅助 3.添加了费用报销单和预付发票核销事项分录的模板，加上了供应商业务关联（预付发票核销单据上费用分摊区有供应商） 但是生成业务事项还是报错供应商错误

## 问题原因

事项分录模版中供应商取值错误

## 解决方案

事项分录模版中供应商取值错误，改为取供应商[报销单费用分摊]后正常
