## 问题现象

出纳模块日记账凭证已删除 但是查询凭证里还有 签字里边也显示

## 问题原因

凭证与日记账之间失去关联，后台清楚凭证外部标识后总账删除凭证即可

## 解决方案

凭证由其他模块传入，无法进入模块修改的情况下需要修改外部凭证
取消凭证的外部标识，例如出纳
update gl_accvouch set coutsysname=''
where iperiod='11' and iyear='2021'and ino_id='3'
update gl_accvouch set ioutperiod=''
where iperiod='11' and iyear='2021'and ino_id='3'
update gl_accvouch set coutsign=''
where iperiod='11' and iyear='2021'and ino_id='3'
