## 问题现象

删除生产订单时，报找不到【生产批号】错误

## 问题原因

批号消失（存货清空了），导致单据删除不了

## 解决方案

数据库语句：
update mo-mo set ProductLotMaster=-1 where docno ='生产订单订单号' 修改生产批号的值为-1
最后去系统中反开工删单
