## 问题现象

料品档案、销售订单、采购订单在审核后，已经上传的附件不能删除

## 问题原因

料品档案、销售订单、采购订单在审核后，已经上传的附件不能删除

## 解决方案

设置数据权限，实体选择附件UFIDA.U9.Base.Attachment.Attachment
条件写：( Attachment.EntityFullName == 'UFIDA.U9.SM.SO.SO' and GetAttachmentDocConditionValue ( Attachment.EntityFullName, FloatToStr (Attachment.EntityID), 'Status&lt;3' ) == 1 ) or ( Attachment.EntityFullName == 'UFIDA.U9.PM.PO.PurchaseOrder' and GetAttachmentDocConditionValue ( Attachment.EntityFullName, FloatToStr (Attachment.EntityID), 'Status&lt;2' ) == 1 ) or ( Attachment.EntityFullName == 'UFIDA.U9.CBO.SCM.Item.ItemMaster' and GetAttachmentDocConditionValue ( Attachment.EntityFullName, FloatToStr (Attachment.EntityID), 'Status&lt;2' ) == 1 )
