## 问题现象

请款单应付单号匹配不出

## 问题原因

未根据单据类型进行单独匹配导致的SrcBillType

## 解决方案

case
when aprfd.SrcBillType = 1 then (select ppo.DocNo from PM_PurchaseOrder ppo where ppo.id = aprfd.SrcBillID)
when aprfd.SrcBillType = 0 then ( SELECT aaa.DocNo FROM AP_APBillHead aaa where aaa.id = aprfd.SrcBillID)
when aprfd.SrcBillType = 3 then (select DocNo from PM_Receivement ppo where ppo.id = aprfd.SrcBillID)
when aprfd.SrcBillType = 2 then aprfd.srcbillnum
end as yfddherp,-- 应付单单号
