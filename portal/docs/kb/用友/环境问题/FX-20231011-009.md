## 问题现象

做1月凭证时报错，提示“分配期间小于科目的启用期间”

## 问题原因

科目启用时间不正确，需要修改

## 解决方案

select * from gl_detail where yearv='2023' and pk_glorgbook = '0001F8100000000026FK' and pk_accsubj='0001F810000000003HD0'
select pk_glorgbook,glorgbookcode,pk_glorg, * from bd_glorgbook where glorgbookcode ='12-2020JYT'
select pk_accsubj,beginyear,beginperiod,* from bd_accsubj where pk_glorgbook = '0001F8100000000026FK' and subjcode = '1801'
update bd_accsubj set beginperiod='01' where pk_glorgbook = '0001F8100000000026FK' and subjcode = '1801'
