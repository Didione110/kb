## 问题现象

服务器登陆010账套提示“更新任务库时发生冲突，请重新注册SQLServer检测到基于一致性的逻辑1/O错误 pageid不正确(应为1:90263，但实际为0:0)。在文件
'E:\U8SOFT\Admin\FWQ\UFSystem.MDF中、偏移量为0x0000002c12e000的位置对数据库ID5中的页(1:90263)执行读取期间，发生了该错误。

## 问题原因

系统库损坏

## 解决方案

1.数据库修复助手，检测010的UFDATA库与UFMETA库无误，检测UFSystem库存在轻微损坏
2.备份010账套、UFDATA库、UFMETA库、UFSystem库文件
3.使用数据库修复助手进行修复，修复到一半系统库断联，进入SSMS查看系统库变为单个用户
4.将此时的系UFSystem（单个用户）进行分离，将原U8soft-fwq路径下的修复了一半的系统库文件进行附加，测试可以正常使用
（知识拓展：SQL SERVER维护数据库或者修复数据库等场景时需要切到单用户模式进行，目的是防止其他用户有相应操作。
 如果不需要为单用户模式了，可以手动在界面修改为多用户模式，也可以用命令修改，例如：ALTER DATABASE 数据库名 SET MULTI_USER；）
