## 问题现象

年结后有150+个账户都是暂停状态，需要手工启用

## 问题原因

用友U8出纳年结设计如此，修改启用参数后可解决当年此问题

## 解决方案

select IsUsed,* from cn_acctinfo where lYear =2023
update cn_acctinfo set IsUsed=1 where lYear =2023 and IsUsed=2
执行后出纳模块运行无问题
