## 问题现象

已结束流程替换知会待办人

## 问题原因

最后一个节点知会节点，由于流程已结束，待办知会人无法替换

## 解决方案

修改数据里的待办人（操作之前先进行备份）

打开替换节点的待办，获取affairId
查询数据库获取要替换人员的id
SELECT id FROM org_member WHERE name='替换人员名称' AND IS_ENABLE=1 AND IS_DELETED=0;
更新ctp_affair表，根据affairId查询id，替换memberId
update ctp_affair SET MEMBER_ID='第2步查出来的id' WHERE id=第一步查出来的affairId;
查询wf_workitem_run，如果没数据再查询WF_WORKITEM_HISTORY
SELECT * FROM WF_WORKITEM_RUN WHERE id=(SELECT sub_object_id FROM ctp_affair WHERE id=第一步查出来的affairId)；
--查询wf_workitem_run没数据才用下面sql查询WF_WORKITEM_HISTORY
SELECT * FROM WF_WORKITEM_HISTORY WHERE id=(SELECT sub_object_id FROM ctp_affair WHERE id=第一步查出来的affairId)；
更新wf_workitem_run/WF_WORKITEM_HISTORY表，根据ctp_affiar里的sub_object_id查询id，替换performer
update WF_WORKITEM_RUN SET performer='第2步查出来的id' WHERE id=(SELECT sub_object_id FROM ctp_affair WHERE id=第一步查出来的affairId);
--查询wf_workitem_run没数据才用下面sql更新WF_WORKITEM_HISTORY
update WF_WORKITEM_HISTORY SET performer='第2步查出来的id' WHERE id=(SELECT sub_object_id FROM ctp_affair WHERE id=第一步查出来的affairId);
