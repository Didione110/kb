# 表单数字控件修改长度总结：
【场景一】表单已经产生了数据，但是数字类型控件未产生数据；
  结论：数字控件的总长度和小数位数长度可以随意修改。
【场景二】表单已经产生数据，并且数字类型控件也已产生数据；
  结论：1、总长度和小数长度可以改大，表单上的数据不会丢失，小数长度改大后已有数据上会自动补0；
           2、总长度和小数长度在表单设计界面上不可以直接改小。
变相改小方法：
（1）表单设计界面把数字类型控件改成文本类型，该操作不会造成数据丢失；
（2）进入应用定制平台-运维中心-字段类型修改，将该控件由文本再改回数字控件，可以同时改小度，最终数据会四舍五入显示。
注意：表单需要发布后运维中心才能修改字段类型；建议修改数据之前做好数据备份
