## 问题现象

通过哪些表能查询门户空间、菜单表以及人员授权数据

## 问题原因

通过哪些表能查询门户空间、菜单表以及人员授权数据

## 解决方案

如下是表关系，具体请项目组技术人员结合数据字典以及数据进行查询和分析：

门户及授权信息：

门户表：portal_set

门户授权表：portal_set_security，关联关系portal_id=id，通过门户授权表的entity_type和entity_id来进行授权。

空间及授权信息：

空间表：portal_space_security

空间授权表：portal_space_fix，关联关系space_id = id，通过空间授权表的entity_type和entity_id来进行授权。

菜单及授权信息：

以下为查询某个指定角色有什么菜单的方法，其余场景可以类推：

1-查询角色id
select id from org_role where code=‘角色编号’

2-通过角色id查询菜单
select * from priv_menu where id in(select menuid from priv_role_menu where roleid=第一步查询的角色id )
