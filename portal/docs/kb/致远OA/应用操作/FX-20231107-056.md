# 当OA短信平台仅用于账号密码找回时，需注意以下几点：
1、授权系统消息转移授权（被授权人员可以通过手机端接收OA系统发出的提醒消息）；不授权发送短信授权（被授权人员可以通过OA系统发送手机短信）。如果设置发送短信授权，被授权人员可以直接通过OA发送短信，短信资源耗用较快，如果不考虑短信资源耗用，可开启该授权。
2、当OA系统启用了短信平台，考虑到短信资源耗用问题，可通过开发手段取消个人启用短信验证码登录选项，避免客户误开启验证码登录，造成短信资源浪费（系统默认不开启短信验证码，用户可自行开启）。
