## 问题现象

致远OA附件下载加密，通过加密后，发现加密后的文件存在乱码问题

## 问题原因

检查附件监听事件代码，发现附件下载时，经过解密，在下载监听事件时加密下载附件是OA加密的文件流，所有存在乱码字符

## 解决方案

在针对下载附件加密前，先将其通过OA内部方法解密，再通过天喻加密软件加密
// 获取下载文件，并进行解密处理
FileManager fileManager = evt.getFileManager();
CtpFile file = fileManager.getFileDecryption(evt.getFileId());
CtpFile tempFile = fileManager.decryptionFile(file);
InputStream tempinput = new FileInputStream(tempFile);
