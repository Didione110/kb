## 问题现象

组织架构人数与私有云致信注册人数不一致

## 问题原因

OA人员状态变化（如离职、不可用等），但未同步至致信私有云服务消除注册数

## 解决方案

一、清理OA服务的致信人员注册信息
1、清理表数据
truncate table uc\_syn\_token;
truncate table zx\_auth\_user;

二、清理私有云服务的致信人员注册信息
1、在私有云服务器上登录mysql（因私有云服务已发布多个版本，根据版本的不同，以下两种方式哪个能进就用哪个）
(a)、mysql -h127.0.0.1 -P4306 -uim -pKx@34#fKN2vuA7Ym
(b)、mysql -uim -h 127.0.0.1 -P4306 -p1qazCDE#

2、进入comcloud\_x表
use comcloud\_x

3、清理表数据
truncate table CC\_DeviceTokenMap;
truncate table CC\_GroupForbiddenMember;
truncate table CC\_GroupInfo;
truncate table CC\_GroupPerson;
truncate table CC\_MsgRelations;
truncate table CC\_UserInfo;
truncate table CC\_UserPushTable;
truncate table CC\_UserSetting;
truncate table CC\_VoipTokenTable;
truncate table CC\_BlockUserPush;
truncate table CC\_McInfo;
truncate table CC\_McRelation;
truncate table CC\_BlockUserInfo;

4、重启rcx服务
supervisorctl restart all

三、到OA服务后台重新授权致信人员
1、登录单位管理员账户，到【致信管理平台】-\&gt;【致信授权管理】中重新进行授权；
2、切换系统管理员角色，到【致信管理平台】-\&gt;【人员信息管理】中查看或更新；
