## 问题现象

人员已离职，升级后文档中心的共享显示了离职人员对文件夹的全部权限

## 问题原因

在8.1版本迭代中，新增了一项功能，文档中心会在人员离职时删除文档相关的所有授权。功能本身非常简单，仅是监听了人员信息变更事件，在离职时删除文档授权。但是在当时没有考虑对历史版本的数据处理，造成在文档相关业务中，还能显示该次迭代升级前离职人员，拥有某些文档的权限。数据本身其实没有什么危害，但是切实对当前管理或使用者造成不好的体验

## 解决方案

解决方案（数据修复）
1、确认离职人员
SELECT id,`name` FROM org\_member om WHERE IS\_DELETED = 0 AND IS\_ENABLE = 0 AND IS\_LOGINABLE = 1 AND IS\_ASSIGNED = 1 AND STATE = 2;
2、确认离职人员数量
SELECT count(1) FROM org\_member om WHERE IS\_DELETED = 0 AND IS\_ENABLE = 0 AND IS\_LOGINABLE = 1 AND IS\_ASSIGNED = 1 AND STATE = 2;
3、确认授权数据
SELECT \* FROM doc\_acl WHERE user\_id in (SELECT ID FROM org\_member om WHERE IS\_DELETED = 0 AND IS\_ENABLE = 0 AND IS\_LOGINABLE = 1 AND IS\_ASSIGNED = 1 AND STATE = 2);
4、如果有需要则备份数据（选择执行）
create table doc\_acl\_backup SELECT \* FROM doc\_acl WHERE user\_id in (SELECT ID FROM org\_member om WHERE IS\_DELETED = 0 AND IS\_ENABLE = 0 AND IS\_LOGINABLE = 1 AND IS\_ASSIGNED = 1 AND STATE = 2);
5、删除授权数据
delete from doc\_acl WHERE user\_id in (SELECT id FROM org\_member om WHERE IS\_DELETED = 0 AND IS\_ENABLE = 0 AND IS\_LOGINABLE = 1 AND IS\_ASSIGNED = 1 AND STATE = 2);
