## 问题现象

报销单撤销删除后，申请单关闭，提示被报销单使用，无法关闭；

## 问题原因

OA报销单流程撤销删除，C4后台监听异常，导致报销锁定金额占用，无法关闭事前申请单

## 解决方案

经核实，报销单OA流程记录已删除，进行C4后台数据修复即可

步骤：先执行查询确认再进行删除，数据修复；删除后金额等第二天会自动修复

-- 查询需要删除的数据
select * from lexmisc4_chargebill where cb_no='报销单号';
select * from lexmisc4_writeoff where w_mainbillno='报销单号';
-- 备份表数据
create table lexmisc4_chargebill_260226 as select * from lexmisc4_chargebill;
create table lexmisc4_writeoff_260226 as select * from lexmisc4_writeoff;
-- 删除数据
delete from lexmisc4_chargebill where cb_no='报销单号';
delete from lexmisc4_writeoff where w_mainbillno='报销单号';
