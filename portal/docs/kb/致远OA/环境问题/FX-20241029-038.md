## 问题现象

报表门户空间模板丢失，一直在转圈圈或提示未正确同步base目录

## 问题原因

进行了服务升级或者迁移没有迁移base目录
服务器中毒base目录下模板文件丢失
从低版本升级文件目录映射有变化导致文件无法正常加载

## 解决方案

服务迁移和升级一般有备份文件将之前的base/resources/capBizPortal下的文件拷贝到新服务器部署位置即可,无需重启
中毒等文件丢失文件找不回来了,这种情况需要将有问题的栏目空间重新配置,有问题的报表模板重新选择才能解决,因为在重新配置的过程中系统会重新下载这个模板文件
如果是7.1版本升级到8.0以上版本,7.1空间模板位置在:base/upload/2007/01/01/capBizPortal下,升级需要将base/upload/2007/01/01/capBizPortal文件拷贝到base/resource/capBizPortal下。迁移之后还是不行
提供修复方案：

备份 cap_portal_good_snapshot
MySQL、Oracle备份：create table cap_portal_good_snapshot_bak as select * from cap_portal_good_snapshot
Sql Server: select * into cap_portal_good_snapshot_bak from cap_portal_good_snapshot

delete from cap_portal_good_snapshot where GOODS_ID = 'pc.bns' or GOODS_ID = 'mobile.bns'

在浏览器输入地址：http://ip地址:端口/seeyon/rest/cap4/bizportal/-1/restore/default

去默认空间界面 此时正常打开，如果默认空间显示空白，可恢复默认并保存下；
