# OA环境检查工具
适用环境：环境检查工具支持V7.1SP1及以上版本协同，支持Windows、
Linux、信创环境下进行使用，依赖jdk1.8或更高版本

功能：对当前系统环境的配置已经参数做检查并给出建议
工具执行结束会生成checkResult_0.0.1.html文件，文件中会详细说明检查结果和解决方法
同时也会指出可能引发的问题

## 解决方案

1、工具安装包获取
 下载地址：https://open.seeyoncloud.com/#/toolbase，或见附件；
2、自动更新
 如果本地已安装检查工具，连网环境下不需要进行下载，工具在启动时会自动更新，选择更新即可；
3、 部署
 下载后的工具zip文件可解压至任意目录，工具启动需要依赖同级目录的jdk，如果同级目录没有jdk，则会使用协同的jdk（通过读取注册表获取jdk目录）。 (注：标准环境有注册表信息，信创环境没有注册表，需要配置JAVA_HOME的环境变量后使用)
具体使用见附件
