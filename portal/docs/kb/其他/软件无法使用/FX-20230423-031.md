## 解决方案

1、在C:Program Files (x86)Common Files Microsoft Shared文件夹里，新建DAO这个目录;
2、复制C: Windows\\SysWOW64里面的dao360.dll文件到上面的DAO目录并注册
如果是32位的操作系统，上面的路径则分别是:
C: Program Files Common Files Microsoft Shared
C: Windows\\System32
