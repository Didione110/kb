## 问题现象

WMS三方仓库中批量打印出库单功能中，个别单据打印三方出库单时候报错无法打印

## 问题原因

批量打印出库单功能是根据BDE连接，当数据中的前后挂号不符，存在全角半角情况下会导致打印报错无法打印

## 解决方案

根据此数据问题，建议在资料更新存储过程中，将对应的常用字段，例如单位名称，地址，商品规格等挂号更新为对应的半角字符显示，例如
update mchk set dzhdh=replace(replace(dzhdh,'（','('),'）',')')
from mchk 
where (dzhdh COLLATE Chinese_PRC_CS_AS_WS like '%（%' and dzhdh COLLATE Chinese_PRC_CS_AS_WS like '%)%')
 or (dzhdh COLLATE Chinese_PRC_CS_AS_WS like '%(%' and dzhdh COLLATE Chinese_PRC_CS_AS_WS like '%）%')
