## 问题现象

WMS在做系统升级时，原系统中表的字段内容可能比标准产品长，实施时不注意上线后就会出异常

## 问题原因

WMS在做系统升级时，原系统中表的字段内容可能比标准产品长，实施时不注意上线后就会出异常

## 解决方案

DECLARE @tname VARCHAR(30) = 'zzwms_ck_kpd_his'

SELECT *
FROM (
SELECT b.name AS cname,b.length,b.xtype
from skwms_hbkx_old..sysobjects a
join skwms_hbkx_old..syscolumns b on a.id=b.id
WHERE a.name=@tname
) a
LEFT JOIN (
SELECT b.name AS cname,b.length,b.xtype
from sysobjects a
join syscolumns b on a.id=b.id
WHERE a.name=@tname
) B ON a.cname = b.cname
WHERE (a.length&gt;ISNULL(b.length,0)
OR a.xtype &lt;&gt; b.xtype)
用于对比两个库中表字段的差异，前面的表是原数据库的，后面的表是新库的，这样可以快速对比出新库里要加的字段，和字段长度问题
