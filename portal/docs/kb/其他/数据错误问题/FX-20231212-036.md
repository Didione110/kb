## 问题现象

T+端已经取消会员打折，POS端还有会员会自动打折

## 问题原因

零售和系统不能同步

## 解决方案

删除会员类型中的通用折扣无效，
在pos端数据库检查select * from aa_dr_membertype，发现POS后台还是存在95折设置，
update from aa_dr_membertype set generaldiscountrate=null where code='01'，后台清空折扣，测试解决
