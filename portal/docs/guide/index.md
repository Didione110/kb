# 快速开始

## 浏览器访问

打开门户首页即可浏览全部知识：

1. **浏览知识库**：左侧分类树按「产品线 → 问题类型」组织，点击展开查看条目
2. **搜索**：点击右上角搜索图标或按 `Ctrl+K`，输入问题描述（如"U8 登录失败"）
3. **查看条目**：每条知识包含元信息（产品线/版本/模块/提交人）、问题现象、原因、解决方案、引用来源

## 知识条目页面说明

每个知识条目页面包含：

| 区块 | 内容 |
|------|------|
| 元信息 | 知识ID、产品线、版本、模块、问题类型、技术栈、关键词、提交人/部门/日期 |
| 问题现象 | 客户遇到的具体问题描述 |
| 问题原因 | 根因分析 |
| 解决方案 | 处理办法（可能含 SQL、配置步骤等） |
| 引用来源 | 钉钉文档链接 + 表格记录 ID，确保可溯源 |
