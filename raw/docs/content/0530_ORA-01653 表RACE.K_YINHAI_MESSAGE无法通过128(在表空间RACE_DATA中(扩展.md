## 问题现象

ORA-01653:表RACE.K\_YINHAI\_MESSAGE无法通过128(在表空间RACE\_DATA中)扩展

## 问题原因

ORACLE数据库单文件最大限制32G，需要增加物理文件

## 解决方案

--查询表空间存储路径
SELECT \* FROM dba\_data\_files t WHERE t.tablespace\_name='RACE\_DATA'; 
--增加下一个文件
alter tablespace RACE\_DATA add datafile 'D:\\app\\race2.dbf' size 512M autoextend on

备注：不一定非要报错再增加文件，预估客户使用规模提前增加文件保障系统运行正常
