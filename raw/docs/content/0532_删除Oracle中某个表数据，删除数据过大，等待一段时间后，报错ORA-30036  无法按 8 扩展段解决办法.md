## 问题现象

删除Oracle中某个表数据，删除数据过大，等待一段时间后，报错ORA-30036: 无法按 8 扩展段解决办法

## 问题原因

删除的数据过大，导致undo表空间所在的数据文件超过32g，执行删除任务失败，且导致操作回滚

## 解决方案

-- 查询undo表空间所在路径
SELECT \* FROM dba\_data\_files t where tablespace\_name ='UNDOTBS1'
-- 增加表空间物理文件
alter tablespace UNDOTBS1 add datafile 'D:\\APP\\ADMINISTRATOR\\ORADATA\\ORCL2\\UNDOTBS02.DBF' size 512M autoextend on
