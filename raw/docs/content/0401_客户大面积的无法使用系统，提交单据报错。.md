## 问题现象

客户大面积的无法使用系统，提交单据报错。

## 问题原因

客户数据库安装在C盘，日志已经沾满了C盘，系统已经无法使用。

## 解决方案

客户数据库‘SQL Server Management Studio’未安装完全部功能，无法在工具上打开数据库收缩日志，使用语句收缩日志：

USE \[master\] -- 使用master数据库
 GO
 ALTER DATABASE seeyon SET RECOVERY SIMPLE WITH NO\_WAIT 
 GO
 ALTER DATABASE seeyon SET RECOVERY SIMPLE -- 修改成简单模式
 GO
 USE seeyon 
 GO
 DBCC SHRINKFILE (N'seeyon\_log' , 1, TRUNCATEONLY) -- 进行日志收缩，
默认文件单位为 M，其中 1 表示将日志文件收缩到 1M，大小可以自己设置。
 GO
 USE \[master\]
 GO
 ALTER DATABASE seeyon SET RECOVERY FULL WITH NO\_WAIT
 GO
 ALTER DATABASE seeyon SET RECOVERY FULL -- 还原为完全模式
 GO
