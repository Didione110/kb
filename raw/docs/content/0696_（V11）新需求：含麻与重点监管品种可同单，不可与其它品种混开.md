## 问题现象

（V11）新需求：含麻与重点监管品种可同单，不可与其它品种混开

## 问题原因

（V11）新需求：含麻与重点监管品种可同单，不可与其它品种混开

## 解决方案

商品后事件增加代码：
if(grid1.currentRow \>=2 && !Utility.isSpace(ds\_ddmx.field("goodsid").value))\{
 // 取当前行的 含麻标识、重点监管标识
 var currIsEphe = ds\_ddmx.getValueAt(grid1.currentRow - 1,"IsEphe"); // 含麻
 var currIszdjg = ds\_ddmx.getValueAt(grid1.currentRow - 1,"k\_iszdjg"); // 重点监管
 // 取第上行的 含麻、重点监管
 var lastIsEphe = ds\_ddmx.getValueAt(grid1.currentRow - 2,"IsEphe");
 var lastIszdjg = ds\_ddmx.getValueAt(grid1.currentRow - 2,"k\_iszdjg");
	// 定义：特殊品 = 含麻 或 重点监管
 var currIsSpecial = (currIsEphe == "Y" \|\| currIszdjg == "Y");
 var lastIsSpecial = (lastIsEphe == "Y" \|\| lastIszdjg == "Y");
 // ============== 核心规则 ==============
 if (currIsSpecial != lastIsSpecial) \{
 alert("含麻与重点监管品种可同单，不可与其它品种混开！");
 ds\_ddmx.deleteRow(); // 删除错误行
 \}
\}

实现效果（已验证）：
通过：
• 全普通品
• 全含麻
• 全重点监管
• 含麻 \+ 重点监管

拦截：
• 普通品 \+ 含麻
• 普通品 \+ 重点监管
• 普通品 \+ 含麻 \+ 重点监管
