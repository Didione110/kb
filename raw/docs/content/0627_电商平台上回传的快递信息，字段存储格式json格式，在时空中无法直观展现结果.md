## 问题现象

电商平台上回传的快递信息，字段存储格式json格式，在时空中无法直观展现结果

## 问题原因

电商平台上回传的快递信息，字段存储格式json格式，在时空中无法直观展现结果，sql server 2016版本一下数据库没有可用函数直接进行转换

## 解决方案

以药师帮为例，表ysb\_RefundOrder中字段orderLogists 存储内容为（ \[\{"orderId": 524236626,"shipperName": "圆通速递","logisticsNo": "YT8742501089052","signedDate": "2025-03-05 14:34:06" \} \]），
根据以下代码可转换成列：
SELECT 
 orderId,
 -- 提取 shipperName 
 SUBSTRING(
 orderLogists,
 CHARINDEX('"shipperName": "', orderLogists) \+ LEN('"shipperName": "'),
 CHARINDEX('"', orderLogists, CHARINDEX('"shipperName": "', orderLogists) \+ LEN('"shipperName": "')) 
 \- (CHARINDEX('"shipperName": "', orderLogists) \+ LEN('"shipperName": "'))
 ) AS kdmch,
```
-- 提取 logisticsNo
SUBSTRING(
    orderLogists,
    CHARINDEX('"logisticsNo": "', orderLogists) + LEN('"logisticsNo": "'),
    CHARINDEX('"', orderLogists, CHARINDEX('"logisticsNo": "', orderLogists) + LEN('"logisticsNo": "')) 
    - (CHARINDEX('"logisticsNo": "', orderLogists) + LEN('"logisticsNo": "'))
) AS kddh,

-- 提取 signedDate
SUBSTRING(
    orderLogists,
    CHARINDEX('"signedDate": "', orderLogists) + LEN('"signedDate": "'),
    CHARINDEX('"', orderLogists, CHARINDEX('"signedDate": "', orderLogists) + LEN('"signedDate": "')) 
    - (CHARINDEX('"signedDate": "', orderLogists) + LEN('"signedDate": "'))
) AS kdrq

```

FROM ysb\_RefundOrder
-- 可选：添加WHERE子句确保字段包含JSON
WHERE 
 orderLogists LIKE '%shipperName%' 
 AND orderLogists LIKE '%logisticsNo%' 
 AND orderLogists LIKE '%signedDate%';
