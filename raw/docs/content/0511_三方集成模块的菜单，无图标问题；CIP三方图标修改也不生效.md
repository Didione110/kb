## 问题现象

三方集成模块的菜单，无图标问题；CIP三方图标修改也不生效

## 问题原因

三方客开产品的菜单，不受标准产品修改，所以CIP三方图标修改也不行

## 解决方案

直接数据库更新菜单图标库表

select \* from PRIV\_MENU where NAME = '企学星'

select \* from PRIV\_MENU where id = '-5089558676849806123'

update PRIV\_MENU set icon = 'workingplan.png' where id = '-5089558676849806123'
