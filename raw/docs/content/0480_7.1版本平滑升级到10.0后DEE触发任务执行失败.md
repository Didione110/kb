## 问题现象

7.1版本平滑升级到10.0后 DEE触发任务执行失败 提示“com.seeyon.v3x.dee.exception.DeeException: code-57001004:REST permission validation failed, user name or password error.
REST permission validation failed, user name or password error.Failed : HTTP error code : 401”

## 问题原因

升级OA后，系统管理员---rest用户管理--默认勾选了 校验token的IP限制导致校验失败

## 解决方案

去掉勾选IP限制后，重置rest密码后 重新配置dee的密码 已正常使用
