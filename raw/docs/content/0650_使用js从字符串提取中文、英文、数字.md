## 问题现象

使用js从字符串提取中文、英文、数字

## 问题原因

使用js从字符串提取中文、英文、数字

## 解决方案

// 1. 提取中文 
str.replace(/\[^\\u4E00-\\u9FA5\]/g,'')

// 2. 提取英文 
str.replace(/\[^a-zA-Z\]/g,'')

// 3. 提取数字 
str.replace(/\[^\\d\]/g,'')
