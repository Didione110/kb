## 问题现象

删除凭证提示出纳已签字，但在出纳取消签字中找不到该凭证。
在应付的发票查询未制单中查不到，已制单有。
在应付凭证处理中找不到该发票。

## 问题原因

客户修改2020年数据，期间有做过用友软件数据升级

## 解决方案

1、做好数据备份；2、用DELETE删除GL\_ACCVOUCH的相关凭证
3、应付发票查询依旧只能在已制单中显示 ，跟踪表后处理完成。
例如：
select cPZNum,cclue,\* from PurBillVouchs where cPZNum='记-0082' 
找到 cclue='AP0000000000344'
注意不能仅按凭证号处理，因为有其他月也有相同凭证号
update PurBillVouchs set cPZNum=null,cclue=null where cPZNum='记-0082' and cclue='AP0000000000344'--采购发票子表
SELECT cPzID,iperiod,\*FROM AP\_DetailVend where cPzID='AP0000000000344'
update AP\_DetailVend set cPzID=null where cPzID='AP0000000000344'--应付款管理
4条语句显示的消息数都是一致的才是正确的。
