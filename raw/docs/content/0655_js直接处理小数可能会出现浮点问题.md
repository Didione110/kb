## 解决方案

/\* Javascript设置要保留的小数位数，四舍五入。
- toFeixd在进位时如果需要进位的末尾是5，如果5后不存在或是0则不进位，否则进位。
- forDight(num,d):数值格式化函数，num,d要格式化的 数字，d要保留的小数位数。
- 这里的方法是先乘以10的倍数，然后去掉小数，最后再除以10的倍数。 */  
function forDight(num,d)\{  
num = Math.round(num*Math.pow(10,d))/Math.pow(10,d);  
return num;  
\}
