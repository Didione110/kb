## 问题现象

## 问题原因

零售录入追溯码时需要有重复录入校验

## 解决方案
1. 零售收银服务端插入监管码表Imeihis的代码中更改oldstate的值区分正负单，见附件1
```
 if(ds_mast.field("ywlx").value.equals("XS")){
 	ds_imieHis.setValueAt(i,"OldState",0);
 	ds_imieHis.setValueAt(i,"NewState",1);		
 }else{
 	ds_imieHis.setValueAt(i,"OldState",1);
 	ds_imieHis.setValueAt(i,"NewState",0);	
 }

```
2. 追溯码输入事件中增加重复校验代码，见附件2

//历史重复扫描校验
 var chk\_imeino = DBUtil.uniqueValue("uf\_sel\_imeino",\{"imeino":IMEINo\});
 if(chk\_imeino \> 0)

对应校验SQL:
SELECT COUNT(\*) as tm
FROM dbo.IMEIHIS a
WHERE a.OldState =0 AND a.IMEINo= :imeino
AND NOT EXISTS (SELECT 1 FROM dbo.IMEIHIS b WHERE a.IMEINo=b.IMEINo AND b.OldState=1)
