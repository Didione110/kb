## 问题现象

时空WMS调度中生成波次提示开票条目数与分摊条目数不一致不一致，无法生成波次

## 问题原因

波次生成存储过程中LJT\_WMS\_BocscTow中拦截，如果出库单中商品，批号重复生成波次系统会合并成一条记录，导致系统报错

## 解决方案

修改存储过程中LJT\_WMS\_BocscTow拦截，修改成开票总数量与分摊总数量不一致。
if exists (select 1 
 from (select sum(shl) as tms 
	 from pf\_phlrmx (nolock) where djbh=@dddjbh 
	 union all
	 select -sum(shl) as tms 
	 from jzorder\_mx (nolock) where djbh=@dddjbh and shl\<\>0) a
	 having sum(a.tms)\<\>0) 
 begin
 set @message='开票总数量与分摊总数量不一致'\+@dddjbh
 raiserror(@message,16,1)
 goto err\_lab
 end
