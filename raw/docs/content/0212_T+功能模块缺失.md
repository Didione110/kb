## 问题现象

T\+功能模块缺失

## 问题原因

环境问题，使用语句修复

## 解决方案

update eap\_menu set Visibility = 1 where name='财务结账'
UPDATE dbo.EAP\_Menu SET Visibility = 1 WHERE Code = 'AA50' AND Name = '价格信息'

UPDATE dbo.EAP\_Menu SET Visibility = 1 WHERE Code = 'AA35' AND Name = '财务信息'
注：缺失什么就执行什么节点的名字，在只有财务模块的情况下，执行完后一定要执行此句

UPDATE dbo.EAP\_Menu SET Visibility = 1 WHERE inID LIKE 'AA\_%' AND Name IN ('部门','员工','往来单位','计量单位','存货','物料清单','仓库','地区','项目','出入库类别','业务类型','收入','费用','账号','结算方式','售价设置导航','售价带出策略','存货价格本','客户价格本','客户折扣','销售价格查询','科目','凭证类别','常用摘要','现金流量项目')

UPDATE dbo.EAP\_Menu SET Visibility = 0 WHERE Code = 'AA5021' AND Name = '售价带出策略'

UPDATE dbo.Eap\_MenuTreeRelation SET isSystem = 0 WHERE Name IN ('部门','员工','往来单位','计量单位','存货','物料清单','仓库','地区','项目','出入库类别','业务类型','收入','费用','账号','结算方式','售价设置导航','售价带出策略','存货价格本','客户价格本','客户折扣','销售价格查询','科目','凭证类别','常用摘要','现金流量项目') AND MenuCode NOT IN ('DSTALBB1003','DST8006')
