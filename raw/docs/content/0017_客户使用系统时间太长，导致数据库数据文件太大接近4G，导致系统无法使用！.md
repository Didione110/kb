## 问题现象

客户使用系统时间太长，导致数据库数据文件太大接近4G，导致系统无法使用！

## 问题原因

客户电脑操作系统版本太老，软件使用时间太长，硬盘类型为FAT32,文件不能大于4G存储.导致软件不能使用。

## 解决方案

解决此问题，可以让客户重新安装新电脑和软件但此占用时间！或者通过批处理将FAT32转换成NTFS，但转换中可能会丢失数据！建议在数据库中添加可以为 primary 组添加新的数据文件来解决这个问题
alter database 库名 add file(NAME = 逻辑文件名,FILENAME = 'c:/实际文件名.ndf'
 或者 选中数据库-\>属性-\>文件：添加一个新文件。
