## 问题现象

v10 v11 v12在使用form.open时均存在跨域问题，即不能打开非当前应用服务器外的文件或地址

## 问题原因

因为早期V10的环境为IE，故对跨域操作支持很不友善，系统底层代码并没有考虑到这一块，dherp之后内核变成了谷歌，对此有了底层支持，但是开发商并未添加

## 解决方案

找到form.js文件搜索关键字Form.prototype.open
找到如下代码进行选择替换即可
	//如果包含点，可能是一个jsp
		if (formid.indexOf('http://') == 0 \|\|formid.indexOf('https://') == 0 ) \{
			url = formid;
		\}else if (formid.indexOf(".jsp") \> 0 \|\| formid.indexOf(".html") \> 0 \|\| formid.indexOf(".htm") \> 0) \{

			if (formid.indexOf("/") != 0) \{
				url \+= "/"
			\}
			url \+= formid;
		\} else if (action == "workflow") \{
			url = this.parameters.contextpath \+ "/" \+ formid \+ ".workflow";
