## 问题现象

时空V10、11在引入一键打印打印图片过程中，均支持http://127.0.0.1:88/formservice?service=attachment.read&content=？方法
但是在V12后不支持了，无法获取

## 问题原因

DHERP针对安全机制做了控制，获取图片附件的时候需要校验jwt的登录信息进行鉴权，故无法直接访问

## 解决方案

找到tomcat的路径Tomcat\\webapps\\ROOT\\WEB-INF\\WEB.XML
找到如下路径，param-value的值为N即可放开图片下载的鉴权服务
	imgcom.artery.form.ImageServletauthenticationY3
