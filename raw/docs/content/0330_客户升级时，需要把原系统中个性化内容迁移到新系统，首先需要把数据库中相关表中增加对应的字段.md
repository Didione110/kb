## 问题现象

客户升级时，需要把原系统中个性化内容迁移到新系统，首先需要把数据库中相关表中增加对应的字段

## 问题原因

对比新老系统表结构，在新系统增加原系统中个性化字段

## 解决方案

DECLARE @tname VARCHAR(30) = 'zzwms\_ck\_kpd\_his'

SELECT \*
FROM (
SELECT b.name AS cname,b.length,b.xtype
from skwms\_hbkx\_old..sysobjects a
join skwms\_hbkx\_old..syscolumns b on a.id=b.id
WHERE a.name=@tname
) a
LEFT JOIN (
SELECT b.name AS cname,b.length,b.xtype
from sysobjects a
join syscolumns b on a.id=b.id
WHERE a.name=@tname
) B ON a.cname = b.cname
WHERE (a.length\>ISNULL(b.length,0)
OR a.xtype \<\> b.xtype)
用于对比两个库中表字段的差异，前面的表是原数据库的，后面的表是新库的，这样可以快速对比出新库里要加的字段，和字段长度问题
